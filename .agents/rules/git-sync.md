# Sincronización Automática con GitHub

- Siempre que se completen cambios, correcciones de errores o nuevas funcionalidades en el proyecto, realiza el commit y push a la rama actual en GitHub (`origin`).
- Mantén mensajes de commit descriptivos y en español o inglés siguiendo buenas prácticas (ej: `fix(whatsapp): ...` o `feat(...)`).
